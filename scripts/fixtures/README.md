The `.c5p` file is a signed, test-only WASM plugin used by `scripts/m1-desktop-smoke.mjs --full` to exercise the real plugin installer, SQLite bindings, config generation, provenance, audit history, and binding controls in the desktop shell. Its signing private key was generated ephemerally and is not stored in the repository, so the fixture cannot be used to sign other packages. Do not treat its signer fingerprint as a production trust anchor.
