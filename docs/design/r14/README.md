# R14 five-tab UI reference

This directory contains the reviewed visual references for issue #69.

- Source archive: `clash5-r14-ui-mockups.zip`, provided in Downloads on 2026-11-04.
- Source archive SHA-256: `8FDD1AFC330DE0AB4BE03F9A2EE65B0A348974BD6F41AFD4ECEDFD08DF06A6FF`.
- Imported files: the five layout-island PNG/SVG sheets, ten light/dark page renders, the six light/dark interaction-state pairs, their six SVG wireframes, and the source layout README.
- Only static visual references were extracted. The archive's HTML prototypes and Python generator scripts were not imported or executed.
- All example names, node data, connection rows, speeds, and status values are illustrative. The application must render live data and its real loading, empty, error, confirmation, and focus states.

The fixed top-level navigation is Home, Proxies, Subscriptions, Plugins, and Settings. The page mapping and interaction rules are specified by GitHub issue #69 and `docs/clash5-ui-design.md`.
