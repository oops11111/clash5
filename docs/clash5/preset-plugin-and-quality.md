# 预置插件与长程质量检测设计

状态：设计草案，尚未实现。PR 暂不开。

本文覆盖两项规划：

1. 预置插件，同时支持内置与签名目录两种分发方式。
2. 长程连接的速度与质量检测。

## 1. 预置插件

### 1.1 内容

预置一个"IPv6 与 DNS 防泄漏"插件，只改两个普通布尔字段：

- 顶层 `ipv6` 设为 `false`。
- `dns.ipv6` 设为 `false`。

插件不修改 `rules`。补丁校验（`validate_plugin_patch`）已禁止 `rules` 键，这一点保持不变。

### 1.2 权限与可写路径

- 权限：`config.read`、`config.patch`。沙箱没有网络和文件访问。
- 可写路径：`/ipv6`、`/dns/ipv6`，只允许这两个字段。
- 安装预览必须列出将写入的路径与值，与现有预览一致。

### 1.3 两种分发方式（都要）

两种方式共用同一套校验与安装路径，签名者都是项目维护者的同一把密钥。区别只在来源与更新方式。

**内置（bundled）**

- 构建时把签名后的 `.c5p` 打进二进制（`include_bytes!`）。
- 启动时用相同的 minisign 流程校验，公钥固定在二进制中。
- 不访问网络。
- 在插件页显示为"内置"，来源不是目录。
- 可以停用、重新启用。不提供卸载；卸载按钮改为停用。
- 随应用版本更新，不需要单独下载。

**签名目录（catalog）**

- 与 #60 的目录流程一致：维护者发布 `index.json` 与签名，用户添加目录时确认签名者指纹。
- 适合后续新增或更新预置插件，不需要发新版应用。
- 目录的下载与校验仍经本地混合端口，隐私约束见 `PRIVACY.md` 第 4.13 节。

### 1.4 验证

- 单元测试：补丁通过 `validate_plugin_patch`；包含 `rules` 的补丁被拒绝；可写路径外的字段被拒绝。
- 配置校验：生成后的配置用 `mihomo -t` 检查。
- 运行时：检查生效的 `ipv6` 与 `dns.ipv6` 值，并能在插件页看到来源（内置或目录）。
- 防泄漏效果：依赖 DNS 泄漏测试，该测试单独立项（见第 3 节）。在它完成之前，只能声称"配置已关闭 IPv6 与 DNS 的对应字段"，不能声称"已防泄漏"。

### 1.5 冲突

与全局 DNS 设置冲突时，沿用现有的合并溯源（provenance）与冲突列表。插件不静默覆盖用户手动设置。

### 1.6 待决定

- 签名密钥由谁持有、如何轮换。轮换会影响内置插件，需要在发布流程中写明。
- 内置插件是否跟随应用版本升级，还是也允许目录覆盖。建议：内置版本跟随应用，目录只能新增，不能覆盖内置 ID。

## 2. 长程连接的速度与质量检测

### 2.1 对象与边界

- 对象：一条链路，或一条路由。测试经过的是完整路径（混合端口 → 选中的链路）。
- 手动启动，可取消，有时长上限与流量上限。
- 不后台轮询，与 #50–#60 的约定一致。
- 不读取或保存下载内容，只保存指标。

### 2.2 测量项

| 指标 | 方法 | 输出 |
| --- | --- | --- |
| 长连接吞吐 | 经测试 URL 下载固定大小文件（默认值待定，设上限） | 中位数、p10 速率 |
| 首字节时延 | 从建立连接到收到第一个字节 | 中位数 |
| 延迟抖动 | 持续 T 秒，每秒一次 `generate_204` 请求 | 标准差、p95 |
| 连接稳定性 | 统计中断与超时次数 | 次数 |

### 2.3 判定

`healthy` / `warning` / `failed` 三档，阈值待定。建议：

- 任一测量项超过阈值，为 `warning`。
- 连接中断或超时达到设定次数，为 `failed`。
- 阈值可在设置中调整，默认值写在代码常量中并在界面说明。

### 2.4 存储

- 复用 `chain_samples` 历史，并扩展指标字段。需要一次 schema 迁移（v9），迁移按现有约定从 v8 升级。
- 保留最近 N 条，N 待定。

### 2.5 实现位置

- `src-tauri/src/clash5/quality.rs`：测量与统计。
- 复用 `fetch_via_core`，继承混合端口、禁止重定向、超时与大小上限。
- 新命令：`clash5_run_quality_test(chain_id, options)`，结果进入检查器历史。
- 统计函数（中位数、p10、标准差、p95）放在纯函数中，便于单元测试。

### 2.6 隐私与成本

- 测试会消耗流量。界面必须在启动前显示预计用量，并受上限约束。
- 测试 URL 可在设置中修改。默认 URL 与 `PRIVACY.md` 第 4.7 节一致。
- 测试不发送订阅、凭证或节点列表。
- 需要在 `PRIVACY.md` 第 4 节补充一条"长程质量检测：用户启动"。

### 2.7 验证

- 单元测试：统计函数的输入输出。
- 集成测试：本地 SOCKS 中转加本地 HTTP 服务器，限速后验证吞吐数值与中断判定。
- 真机：在设备验证清单 G1 的链路上运行一次，记录结果并回报 #60。

### 2.8 待决定

- 默认测试 URL 与文件大小。
- 阈值默认值。
- 是否允许定时运行。建议不允许，保持"不后台轮询"。

## 3. 与现有工作的关系

- 预置插件：在设备验证清单 F 组后追加 F10–F12，覆盖内置与目录两种来源。

- DNS 泄漏端到端测试：单独立项，是两项的前置条件之一。本文不设计它。
