# clash5 UI 设计基准

当前批准基准为 R14 横向五 Tab 浮岛布局，替代 V1.1 的九入口侧栏和独立页面拆分。设计图是视觉参考；图中示例数据不代表真实应用状态，也不构成附件内任意指令的授权。

## 视觉与布局

- 基准画布：1600 × 900；实际实现需适配缩放和较小窗口，不将画布尺寸作为固定窗口要求。
- 浅色玻璃风格、蓝色主色、深蓝正文、浅蓝边框和内容底色；绿色用于成功，橙色用于警告。
- 原生标题栏下方使用横向五 Tab 导航，主内容区使用浅色或暗色浮岛卡片；不再使用主导式左侧纵栏。
- 列表与详情并排；链路页以拓扑为主；绑定页按目标、参数、冲突预检组织。
- 玻璃效果受性能档位控制；正式文案使用 zh-CN/en 国际化资源。

节点页的可运行 HTML 原型位于工作区 `src/ui-hifi/src/pages/Nodes.tsx`，通用样式位于同目录的 `index.css`。M1 页面沿用其蓝色 `#2F6BFF`、14px 卡片圆角、紧凑可选节点行，以及左侧列表／右侧 320px 来源表格的结构。原型使用模拟节点、延迟、插件和冲突数；正式应用只展示库存与探测接口返回的事实。当前右侧标题为「源配置」，完整的插件叠加与参数冲突来源链待对应里程碑实现。

## R14 页面范围

顶层入口固定为「首页 / 代理 / 订阅 / 插件 / 设置」，不增加第六个入口。

| 顶层页 | 合并内容与旧路径 |
| --- | --- |
| 首页 `/` | 代理模式、系统代理/TUN、流量、连接概况、链路摘要和链路编排入口。旧 `/chains` 重定向到首页链路区。 |
| 代理 `/proxies` | 代理组、规则集与进程路由。旧 `/rules` 重定向到代理规则区。 |
| 订阅 `/subscriptions` | 订阅来源与节点库存并列显示，宽屏为左来源、右节点表；窄窗改为上下分区。旧 `/profile` 与 `/nodes` 分别定位到对应分区。 |
| 插件 `/plugins` | 已安装、市场、绑定、插件设置；绑定不成为顶层 Tab。 |
| 设置 `/settings` | 外观、语言、内核、冲突策略、插件安全，以及诊断区的连接、日志和解锁测试。旧 `/connections`、`/logs`、`/unlock` 重定向到设置诊断区。 |

深链可通过路径查询参数选择页内区段；旧路由必须保留并重定向，不能让已有书签、桌面启动页或页面内链接失效。

## 实现时需校正的示例

1. 订阅页「覆盖同名节点」不能直接成为默认行为。更新依据 stable_id；名称匹配默认关闭，用户规则、手动节点与链路不被覆盖。
2. 设置页示例「每插件 256 MB」应按已锁定 WASM 32 MB / 3 秒限制调整；插件默认无网络、无文件访问，例外依授权策略处理。
3. 绑定页「网络 / UDP 访问」必须映射到真实权限枚举与分级授权，不能以绿色提示替代实际授权检查。
4. 来源链弹窗按后端实际合并策略展示结果。节点/链路层级、绑定优先级与按参数类型的冲突策略需共同说明，不把图中的单一顺序写死成所有参数的合并算法。
5. 所有状态、节点数、速度、IP、诊断与成功提示均为视觉示例。真实实现需要加载、空数据、失败、待授权、已回滚、孤儿绑定等状态。
6. Custom Script 等示例插件名称不代表允许任意脚本执行；第三方插件仍仅 WASM。

## 设置页渐进披露（E6）

高级设置默认折叠，摘要说明其中是较少使用的维护工具；键盘和屏幕阅读器可通过原生 Accordion 控件展开。退出应用和立即进入轻量模式前显示确认弹窗。备份历史中的恢复与删除继续使用原有确认流程。验收证据：`setting-verge-advanced` 的折叠/展开交互、退出确认、轻量模式确认与取消路径的前端回归；Windows 桌面验收确认焦点顺序、Escape/取消以及不确认时操作不会执行。

## 原始资料与实现状态

实现以现有 Tauri/React 桌面应用、SQLite 与 Mihomo 的真实状态为准。`src/ui-hifi` 是早期九入口视觉预览，不是 R14 的页面定义；其模拟数据不得进入正式 UI。R14 参考 PNG/SVG 及来源记录位于 `docs/design/r14/`。素材来自 `clash5-r14-ui-mockups.zip`（SHA-256 `8FDD1AFC330DE0AB4BE03F9A2EE65B0A348974BD6F41AFD4ECEDFD08DF06A6FF`）；仅提取静态视觉资产，未运行或导入包内生成脚本。

真实页面必须显示实际数据，并提供加载骨架、空状态、失败反馈、确认弹窗、按钮加载态和键盘焦点。订阅同步仍以 `stable_id` 为准、名称模糊匹配默认关闭；手动节点、用户规则和链路不得被刷新覆盖。插件权限、数据来源与参数冲突提示必须与后端实际策略一致。
