clash5 Browser Privacy

Add a hostname to apply a regional profile to that site and its subdomains. More specific hostnames take precedence. Changes apply after reloading the page.

HostnameProfile

This extension changes browser language, default date/time zone, and the Accept-Language request header. It does not change your IP, DNS path, WebRTC address, cookies, hardware, Canvas, WebGL, or every fingerprint signal. The clash5 IPv6/DNS guard is a separate network setting.
